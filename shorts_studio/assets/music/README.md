Fon musiqasi uchun `.mp3` fayllarni shu yerga tashlang (masalan, YouTube Audio Library'dan bepul, mualliflik huquqisiz treklar).

Kayfiyat bo'yicha papkalarga ajratsangiz, Claude ssenariyga mos kayfiyatdagi trekni tanlaydi:

```
music/mysterious/   music/epic/   music/scary/   music/uplifting/   music/funny/
```

Kerakli kayfiyat papkasi bo'sh bo'lsa, shu papkadagi istalgan trek ishlatiladi. Musiqa ovoz chiqqanda avtomatik pasayadi.
